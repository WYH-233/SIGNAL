# Workflow and algorithm details

SIGNAL is organized into three modules: `input_preprocessing/` prepares inputs, `model_training/` trains the graph-attention model, and `output_generation/` exports attention scores and grouped loops. `SIGNAL.py` is the command-line entry point that connects graph-input construction, training and output generation. The command-line workflow is parameterized for user-supplied datasets; some included upstream ArchR/Cicero scripts retain settings from the A549 case.

## 1. Hi-C preparation

Hi-C utilities in `input_preprocessing/hic_processing/` convert Juicer `.hic` contacts, extract chromosome-wise observed/VC contacts, call insulation boundaries and calculate MD-KNN DoD/TAD strength. Individual scripts accept file paths and relevant parameters: `01_split_hic_observed_vc.py` accepts the Hi-C path, output directory and resolution; `03_convert_cool_to_tad_boundaries.py` accepts the cooler path, output directory, resolution and insulation window; the format/conversion scripts accept input and output paths.

## 2. scATAC-seq and graph inputs

The R scripts in `input_preprocessing/scatac_processing/` create ArchR/Cicero co-accessibility and metacell accessibility matrices; Python helpers convert and merge accessibility links. The model CLI starts from these prepared matrices/tables. `SIGNAL.py build-inputs` (or `input_preprocessing/build_model_inputs/01_prepare_signal_model_inputs.py`) combines an accessibility matrix, candidate interactions and Hi-C edge signal into per-chromosome model inputs. Supply file paths, chromosome selection and compute device through CLI arguments.

## 3. Signal model

`model_training/train_signal_model.py` loads per-chromosome graphs and a TAD-strength BED, creates two masked graph views and trains a GATv2 encoder in a GRACE-style contrastive objective. Checkpoints and graph caches are written to the selected output directory. `output_generation/export_high_group_loops.py` computes attention-derived scores for graph edges, normalizes the scores and applies K-means (`k=2`) to produce high- and low-group loop tables.

`SIGNAL.py run` trains the model and exports loop groups in one invocation. Training epochs, save interval, input paths, chromosome set, model dimensions, contrastive mask probabilities, optimizer settings, random seeds and device are command-line parameters. The checkpoint can be selected with `--checkpoint-epoch`; otherwise, the latest saved checkpoint is used. Preserve the exact parameter values and software versions used for the manuscript analyses.

## Outputs and provenance

This algorithm package excludes analysis results, downstream biological interpretation and source data. Keep raw inputs, generated intermediates and checkpoints in a documented data repository or controlled storage location, not in this code repository. Record checksums, software versions and analysis parameters for the final deposited release.

Attention export writes raw, directed three-column scores to `<outdir>/weights_combined_<epoch>/<chrom>_attention_score.csv` and converts region IDs (`chrom:start-end`) into seven-column `<outdir>/<chrom>_attention_score_true.bedpe` tables. Both directions are retained, and self-loops are excluded. Clustering reads only the BEDPE files generated by the current export, writes normalized scores under `max_min_norm/`, and writes per-chromosome and combined high-group BEDPE files under `max_min_norm/kmeans_2_groups/high_groups/`. Empty graphs, missing attention inputs, and fewer than two distinct scores produce an explicit error.

MD-KNN uses a fixed nearest-neighbor count of `k=1`. The optional `-k` argument accepts only `1`; other values are rejected. This setting is independent of the downstream K-means cluster count (`k=2`).
